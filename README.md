## Read-only employee accounts
Active employees assigned to levels -10 or -20 receive a local read-only account automatically:
- Username: employee number
- Temporary password: `RP` + employee number

Example: employee 392 uses username `392` and temporary password `RP392`.

## Included in this build
- RP IA branding and eagle app icon
- English / Spanish selection before sign-in and in My Profile
- Personal password-change screen
- Modern responsive interface
- RP Brain local adaptive recommendation ordering
- Read-only employee profiles
- Administrator-controlled evaluator level and permissions
- Separate permission for METL management and personnel management
- Complete workbook baseline: personnel, tasks, subtasks, matrix, evaluators, sources, assessments
- Exact personnel search by full or partial employee number and name
- Add, change, and remove photos for existing personnel
- Offline service-worker cache

## Important pilot limitation
Data, passwords, photos, and RP Brain learning are stored in the browser on the current device. Enterprise deployment requires company authentication and centralized storage.
