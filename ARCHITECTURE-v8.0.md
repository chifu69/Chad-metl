# RP IA Enterprise Platform v8.0

## Architecture

### User Modules
Dashboard, Personnel, METL & Subtasks, Readiness Matrix, Assessments, Corrective Actions, Knowledge Center, Notifications, Audit Trail, My Profile, and Administration.

### Enterprise Modules
Enterprise landing page, Server Configuration, Diagnostic Center, Security/Permission Assurance, and Backup & Restore.

### 20 Core Engines
1. RP Brain
2. Natural Language Engine
3. Reasoning Engine
4. Workflow Engine
5. Rules Engine
6. Knowledge Engine
7. Search Engine
8. Predictive Engine
9. Audit Engine
10. Competency Coach Engine
11. Experience Engine
12. Evidence Engine
13. Certification Engine
14. Readiness Integrity Engine
15. Data Quality Engine
16. Training Effectiveness Engine
17. Coverage Resilience Engine
18. Recertification Engine
19. Permission Assurance Engine
20. Dependency & Impact Engine

The engines are invisible to normal users. Ask RP Brain coordinates them. Technical status is available only through the administrator-only Diagnostic Center.

## Interface changes
- Plant Intelligence and RP Brain are integrated into Dashboard.
- Ask RP Brain appears beside Readiness.
- Assessments and Assessment History are unified.
- Export Dashboard was removed.
- Engine Center was removed from user navigation.
- Diagnostic Center was added under Enterprise.
- Example employee names use generic demo names.
