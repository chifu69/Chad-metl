RP v9.11.0 — Assigned Assessments Workflow

BASE
RP v9.10.1 Assessment Flow Progress + Save Fix.

NEW WORKFLOW
1. Administrator opens Assigned Assessments.
2. Selects associate, METL task, due date, priority, and assigned evaluator.
3. Evaluator list is restricted by the METL task required level.
4. Assignment is saved with Assigned status.
5. Associate sees the assignment in My Assigned Assessments and on the personal dashboard.
6. Assigned evaluator sees the associate in Assessments Assigned to Me and on the evaluator dashboard.
7. Evaluator opens the assignment; RP preloads associate/task and starts the existing Assessment Session.
8. When the assessment is saved, the assignment changes to Completed and links to the signed assessment session.
9. Administrator can see all assignments and cancel active assignments.
10. Notifications include assigned/due/overdue assessment work.

IMPORTANT PILOT LIMITATION
RP still stores pilot data in the local browser. Assignment visibility across DIFFERENT devices
requires the planned centralized server/database. In the current local pilot, accounts using the
same stored dataset can see the workflow, but separate phones/computers do not automatically sync.
