RP v9.26.0 — Approved Evaluator Management

Built directly on stable RP v9.25.2.

NEW
- Administration includes an Approved Evaluators management list.
- Admins can add, edit, activate, and deactivate evaluators without rebuilding RP IA.
- Active evaluators receive a linked evaluator login automatically.
- Existing workbook evaluators are linked to accounts, including Ronnie Kennedy,
  Francis Arthur, Amy Neloms, Tony Pergrem, John McCord and Production Supervisors.
- Deactivation preserves historical assessment records, disables login, and removes
  the evaluator from future assignment choices.
- Evaluator authorization level continues to control task eligibility.
- Temporary evaluator passwords can be reset from the evaluator editor.

POC AUTHENTICATION NOTE
Automatically generated evaluator accounts use a temporary local password derived
from the evaluator ID and require password change at first login. Production should
replace this with IT-approved company authentication/SSO.
